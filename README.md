# 🎓 Student Performance Prediction System

A beginner-friendly, end-to-end Machine Learning project that predicts whether a student is likely to **Pass** or **Fail**, with a Streamlit web app on top.

## Project description
Given a student's study habits and academic record, the model estimates the probability of passing. The goal is **early support**: flag students who may struggle while there is still time to help. The dataset is synthetic (generated by `src/generate_data.py`) and intentionally messy, so the project also practises real-world data cleaning.

## Features
- Realistic messy dataset (missing values, duplicates, wrong values, inconsistent text)
- Reusable cleaning code and exploratory charts
- Three models compared: Logistic Regression, Decision Tree, Random Forest
- A single saved scikit-learn Pipeline, so training and prediction use identical preprocessing
- Streamlit app with input validation, probability, a visual indicator and a plain-English explanation

## Technologies used
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Streamlit · Joblib

## Machine Learning workflow
1. Generate / load data → 2. Explore → 3. Clean (rule-based) → 4. Train-test split → 5. Pipeline (feature engineering, imputation, scaling, encoding) → 6. Train 3 models → 7. Evaluate (accuracy, precision, recall, F1, confusion matrix) → 8. Pick best by cross-validated F1 → 9. Save with Joblib → 10. Serve with Streamlit

## Installation
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## How to run
Run every command from the project root folder.
```bash
python -m src.generate_data   # 1. create data/students_raw.csv
python -m src.eda             # 2. (optional) print exploration + save charts
python -m src.train           # 3. clean, train, evaluate, save the model
streamlit run app.py          # 4. open the web app
```

## Model evaluation
Results on the 300-student held-out test set:

| Model | Accuracy | Precision | Recall | F1-score |
|---|---|---|---|---|
| **Logistic Regression** (selected) | 0.830 | 0.870 | 0.825 | 0.847 |
| Decision Tree | 0.810 | 0.896 | 0.754 | 0.819 |
| Random Forest | 0.827 | 0.852 | 0.842 | 0.847 |

The three models are close; the simplest one was selected using cross-validated F1 on the training data. Your numbers may differ slightly on other library versions.
